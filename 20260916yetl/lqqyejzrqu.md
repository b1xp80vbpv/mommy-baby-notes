# 吃地屈孕酮片怎么肚子疼，地屈孕酮片推迟月经原理

> 更新时间：2026-09-16 (UTC+8)

很多药物的使用在使用的时候都是伴随着副作用的，所以医生在用药的时候都需要患者做一系列相关的检查，以避免意外情况的发生，肚子痛是一种常见的药物副作用，发病的时候人们痛苦不已，那么吃地屈孕酮片怎么会肚子痛呢?
吃地屈孕酮片怎么肚子疼
　　吃地屈孕酮片肚子疼是因为它的副作用出现造成的，地屈孕酮片副作用主要有以下几点：第一点，对于血液和淋巴系统的影响，可发生溶血性贫血。第二点，对于免疫系统的影响，可发生超敏反应。第三点，影可响神经系统疾病，可表现为头痛、偏头痛、抑郁、精神紧张。第四点，对肝胆系统的影响，可导致肝功能异常，有时伴有黄疸、腹痛等。第五点，对于皮肤的影响，可发生过敏性皮炎，例如皮疹、瘙痒、寻麻疹。第六点，对于生殖系统的影响，部分患者可发生乳房疼痛。

　　地屈孕酮片的副作用，极少数病人可以出现突破性的出血，一般增加剂量即可防止。往往是由于不规则的服用地屈孕酮片，或者中间有漏服等因素引起突破性的出血。服用地屈孕酮片期间，可能会有轻微的出血、经期血量的改变、闭经、身体不适、头晕、头痛、恶心、呕吐、腹痛、肝功能改变、黄疸比较少见、乳房疼痛、瘙痒、皮肤过敏、荨麻疹、情绪忧郁、偏头痛、精神紧张、水肿、性欲改变等副作用。这些副作用在每个人的身上并不是全部出现，有的人副作用可能明显，有的人副作用相对不明显。由于地屈孕酮片属于孕激素的药物，需要在门诊医生的医嘱下，进行正规的服用，副作用相对比较少。

　　地屈孕酮片是一种口服孕激素，可使子宫内膜进入完全的分泌相，从而可防止由雌激素引起的子宫内膜增生和癌变风险;地屈孕酮无雌激素、雄激素及肾上腺皮质激素作用;地屈孕酮不产热，且对脂代谢无影响。在地屈孕酮的临床试验和/或上市销售使用中报告的不良反应如下：来自上市后与地屈孕酮相关且发生频率不详的其他不良反应：良性、恶性及未详细说明的肿瘤(包括囊肿和息肉)、孕激素依赖性肿瘤大小的增加(例如，脑膜瘤);精神疾病：抑郁情绪、精神紧张;其他：呕吐、性欲改变;生殖系统和乳腺疾病、乳房肿胀;与雌激素-孕激素治疗相关的不良反应：乳腺癌、子宫内膜增生，子宫内膜癌、性激素依赖性肿瘤(恶性/良性)、静脉血栓形成、心肌梗死，心血管意外。
地屈孕酮片推迟月经原理
　　这个药物属于孕激素，可以推迟月经，也可以促使来月经来潮，也有保胎的作用。

　　如果是由于孕酮低而导致的月经推迟，那么服用地屈孕酮片后来月经了，那么可以暂时停药，具体还需要看你为什么要服用地屈孕酮片。

　　如果月经不调，可以在月经第二天化验激素六项检查，根据具体情况调理，平时注意生活作息规律，避免熬夜，加强营养。

　　应该停药，不可以再继续服用了，在月经期间不要吃生冷辛辣刺激性食物，保持外阴清洁，勤换卫生垫，穿棉质透气性好的内衣，每天更换。

　　建议患者在使用地屈孕酮片的时候需要正常服用六天左右的时间，而且很多的患者都会在服用药物之后的一周左右就会来月经，但是这种情况也是因人而异的。

　　患者注意在服用了药物之后，需要控制自己的饮食，而且还不能有熬夜喝酒的情况出现，否则也会影响到患者的药效。

　　地屈孕酮片为一种白色薄膜衣片，除去包衣后显白色的药品，能治疗痛经、子宫内膜异位症、发性闭经、月经周期不规则、功能失调性子宫出血、经前期综合征、孕激素缺乏所致先兆性流产或习惯性流产、黄体不足所致不孕症。

　　但是这种要对于不同的病吃法是不一样的。

　　2.子宫内膜异位症

　　从月经周期的第5至25天，每天口服地屈孕酮2-3次，每次口服地屈孕酮1片(以地屈孕酮计10 mg)。

　　4.止血的剂量

　　5.预防出血的剂量

　　从月经周期的第11至25天，每次口服地屈孕酮1片(以地屈孕酮计10 mg)，每日2次。

　　6.闭经

　　从月经周期的第1至25天，每日服用雌二醇，每天1次。从月经周期的第11至25天，联合用地屈孕酮，每天2次，每次1片(以地屈孕酮计10 mg)。

　　7.经前期综合征

　　从月经周期的第11-25天，每日口服地屈孕酮2次，每次1片(以地屈孕酮计10 mg)。

　　会的，孕酮片停用后也会引起撤退性出血，不要用于推迟月经，会造成月经不调。一般的情况下，可以在月经来潮前五天开始连续服用，有推迟月经的作用，但是一般的情况下，不建议使用药物推迟月经的，否则会引起月经不规律的。所以知道地屈孕酮片的用法用量是很重要的，下面就来说说各种不同的疾病怎么服用地屈孕酮片:1. 痛经从月经周期的第5至25天，每日2次，每次口服地屈孕酮1片(以地屈孕酮计10mg)。 2. 子宫内膜异位症从月经周期的第5至25天，每天口服地屈孕酮2-3次，每次口服地屈孕酮1片(以地屈孕酮计10mg)。 3. 功能性出血 4. 止血的剂量每次口服地屈孕酮1片(以地屈孕酮计10 mg)，每日2次，连续5-7天。 5. 预防出血的剂量从月经周期的第11至25天，每次口服地屈孕酮1片(以地屈孕酮计10 mg)，每日2次。
