# 不是有月经就能怀孕吗？那怀孕要看什么？

> 更新时间：2026-09-16 (UTC+8)

**· 能不能怀孕看什么 ·**
许多人觉得只要有规律的月经就表明有健康的生育能力，不见得如此，许多问题是隐藏在深处的，或者是不影响月经的。

女性身体通常有两个输卵管，子宫两侧各一个。

这些输卵管有助于将卵子从卵巢引导到子宫，精子从子宫颈到子宫，并通过输卵管找到卵子。当卵子通过输卵管时，可以进行受精了。

在某些情况下，如果出现了障碍物，会阻止卵子沿着输卵管向下移动，叫做输卵管阻塞。

输卵管阻塞是女性因素不孕的常见原因之一，还有排卵障碍、子宫内膜异位症和盆腔粘连等其他问题。
输卵管阻塞的主要原因是盆腔炎，通常是由传播感染引起的。

其他可能阻止卵子和精子通过输卵管正常运输的疾病是子宫内膜异位症、先前手术引起的骨盆粘连、非输卵管感染(如阑尾炎、盆腔结核和结节性输卵管炎等)。

输卵管阻塞可影响输卵管远端、近端或整个输卵管，远端输卵管阻塞比近端输卵管阻塞常见，由于这种类型的阻塞在卵巢附近的末端，可能由输卵管积水、盆腔粘连等引起。

某些情况下，只有一个管阻塞，另一根通畅的话，仍然有机会可以怀孕，因为卵子仍然可以通过未受影响的输卵管。但是，如果长期没有干预，可能导致其他问题。

为了诊断输卵管阻塞，医生可能建议进行以下的检查：

1.子宫输卵管造影：X光线可见的液体染料通过导管注入并填充子宫和输卵管，以便进行X线扫描。

2.腹腔镜：在腹腔镜检查期间将染料注入输卵管中。

3.宫腔超声造影：超声检查用于观察经宫颈导管输液后的子宫和附件。
